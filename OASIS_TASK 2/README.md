# Oasis Infobyte - Web Development & Designing

## Level 1 - Task 1: Landing Page

This project is created according to the Oasis Infobyte Level 1 Task 1 requirements.

### Project Title
SkillUp Academy - Landing Page

### Technologies
- HTML5
- CSS3

### Features Included
- Sticky navigation bar with multiple navigation links
- Hero section with headline, subheadline and call-to-action buttons
- Features section
- About section
- Call-to-action section
- Footer with contact/social-style links
- Consistent colour palette
- Responsive design for mobile screens
- Proper spacing, margin, padding and box-sizing
- Different typography sizes for headings and body text

### Files
- `index.html` - Main webpage
- `style.css` - Complete styling
- `README.md` - Project information

## How to Run
1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in any web browser.
