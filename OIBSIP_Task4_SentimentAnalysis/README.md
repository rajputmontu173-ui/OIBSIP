# OIBSIP Data Analytics - Level 1 - Task 4: Sentiment Analysis

This project follows the provided Task 4 checklist: class distribution, text preprocessing, TF-IDF, 80/20 split, Naive Bayes + Logistic Regression, accuracy/precision/recall/F1, confusion matrices, sentiment distribution, WordClouds, 5-error analysis and conclusion.

## Run
```bash
pip install -r requirements.txt
python sentiment_analysis.py
```
Or open `Sentiment_Analysis.ipynb` in VS Code/Jupyter and run all cells.

The included CSV is a reproducible practice dataset with positive, negative and neutral customer-style reviews.
